# summarize-video-course

一个面向公开使用的本地视频课程整理 Skill，当前公共版为 v3.3。

它将本地课程视频、字幕或逐字稿整理为七项文字资料：

- 课程总览
- 逻辑稿
- 时间戳逐字稿
- 知识点卡片
- 案例与金句
- 质量问题清单
- `media_index.json` 来源索引

## 公共版说明

这个目录只包含通用 Skill 规则、通用参考标准和占位示例，不包含任何真实课程视频、音频、字幕、逐字稿、课程笔记、个人路径或内部项目状态。

公共版保留了 v3.3 的核心能力：

- “完成”三证据；
- 逻辑稿人读闸门；
- 首课同类故障熔断修复；
- 批内技术修复免重复确认；
- 三副本同步与可回退检查；
- 课程结束时的“无下一批”闸门与全课程终检；
- 唯一 `run_status.json` 状态记录、最终人工确认和课程知识地图；
- 知识点覆盖清单和动态卡片字段；
- 无声/纯画面视频分流；
- 原话、模型整理、意译和重点核对分级；
- 公开仓库内容脱敏检查。

## 使用原则

默认在本地处理课程内容。源视频保持只读，正式输出只保留文字和 JSON。不要把课程内容上传到公共 GitHub 仓库，也不要把绝对路径、用户信息、密钥或运行日志提交到仓库。

如果要把本 Skill 安装到支持 Skill 的工具中，请将 Skill 文件夹复制到该工具的 Skill 目录；如果只是存档或分享，直接将本目录上传到 GitHub 即可。上传前仍应运行一次隐私和密钥扫描。

## 公开前检查

- 仓库中没有视频、音频、字幕、逐字稿或真实课程笔记。
- Markdown、JSON、YAML 中没有个人姓名、课程名称、客户信息和内部编号。
- 没有 `C:\Users\...`、`/Users/...`、网盘路径、局域网地址或设备信息。
- 没有 API key、OAuth token、密码、生产配置或私人仓库地址。
- 示例内容全部是占位内容，不代表任何真实课程或平台。
- 已选择适合自己的开源许可证；未添加许可证时，不要对外承诺他人可以复制、修改或再发布。
