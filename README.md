# summarize-video-course

一个面向公开使用的本地视频课程整理 Skill，当前公共版为 V3.29.0。

它将本地课程视频、字幕或逐字稿整理为七项文字资料：

- 课程总览
- 逻辑稿
- 时间戳逐字稿
- 知识点卡片
- 案例与金句
- 质量问题清单
- `media_index.json` 来源索引

## 公共版说明

V3.29.0 改为外部工具只准备完整机械证据，Codex从完整来源一次定稿；新V2冻结全部引用资产，旧八项只读兼容。提取质量不等于知识质量，每课独立复核仍必做；进度显示证据/复核/发布三个集合，平稳阶段静默。详见[双工具标准](references/dualtool-mechanical-evidence-standard.md)。

V3.28.1 明确具体例子只用课程原例，不靠 AI 编故事补细节；生成与独立复核同时执行 [来源与学生可理解性标准](references/concrete-example-standard.md)。

这个目录只包含通用 Skill 规则、通用参考标准和占位示例，不包含任何真实课程视频、音频、字幕、逐字稿、课程笔记、个人路径或内部项目状态。

公共版保留了 v3.11–v3.24 的课程整理、质量回归和收尾能力；v3.25 增加课件独立核对，v3.26 增加本地运行与发布冻结规则，V3.27.0 增加发布接续自检，V3.28.0 增加条件验收、收尾一致性和双工具实测记录：

- “完成”三证据；
- 逻辑稿人读闸门；
- 首课同类故障熔断修复；
- 批内技术修复免重复确认；
- 用户验收留证后，使用单写者、可回滚的 `course_closeout.py` 生成目录、手册、资料索引与课程首页；
- 严格终检可在收尾中间阶段运行，实际重新打开课程入口后才写 `course_complete`；
- 每批提供可读实时进度，至少完成两节实测前不猜测 ETA。
- 三副本同步与可回退检查；
- 课程结束时的“无下一批”闸门与全课程终检；
- 唯一 `run_status.json` 状态记录、最终人工确认和课程知识地图；
- PDF、PPT、Word、图片课件的本地提取、OCR 来源标注、原件保留和映射歧义处理；
- 逐字稿完成后的课时筛选：导览、前言和平台操作说明先交筛选结论，不硬凑知识卡片；
- 知识点覆盖清单和动态卡片字段；
- 无声/纯画面视频分流；
- 原话、模型整理、意译和重点核对分级；
- 公开仓库内容脱敏检查。
- 长任务运行状态分层、最长 5 分钟心跳、疑似卡住/孤儿进程判定和主动完成通知；进程存在或 CPU 占用不再被当作完成证据。
- 长课时阅读层的长输入降载、模型上下文/输出/超时上限，以及超时后的安全断点恢复。
- 缺失来源重新出现后的独立恢复批次、历史记录保留和源指纹复核。
- 只发布已确认的课件知识稿、页面筛选记录和实际引用关键图，不把整份 OCR 技术稿混入正式知识库。
- 课程批次切换时复用同一个固定实时进度入口，不要求用户重新保存链接，也不因心跳重复发消息。
- 用户阅读前强制审计知识点覆盖、复用公式/表达、完整案例和选择性画面知识；首次失败只做一次局部自修复，仍失败则阻断发布并保留断点。
- 课时完成百分比与批次发布状态分开显示；生成 100% 不再被误报为批次或课程完成。
- 正式批次只追加不覆盖，输出路径固定指向 `课时资料/`，发布异常需可见并回滚本批新增内容。
- 用户说“继续/下一批”时从真实断点续接，不重复启动同批进程；进度同时显示当前课时阶段、批次百分比和批次状态，生成 100% 后必须明确通知发布验证与人工验收。
- 正式知识课数量与导览/前言等跳过项分开统计，恢复批次结束后仍执行全课程收尾。
- 显式区分 `pilot/formal/recovery`，正式课时校验课程名并清除小样/暂存身份。
- 已发布课时修订后同步副本、刷新课程索引并重跑全课程终检。
- 对长课、异常卡片量、ASR/专名/公式/来源差异建立高风险人工审读队列。
- 私有权威版到公开版使用确定性同步、结构校验和隐私扫描。
- 开工前建立覆盖视频、课件、图片和未知格式的全部来源清单；最终现场多出或缺少一个文件都会阻止完成。
- 只选择性保存真正承载知识的视频关键画面；表格、流程图、漏斗和思维导图使用原图加结构化解读，不能用扁平 OCR 代替。
- PDF/PPT 页面必须唯一分为保留、上下文或排除；课件唯一映射到课时时必须真正融合进阅读层。
- 课程完成拆成结构、来源、画面、课件融合、自动验证和人工验收六层，全部通过后才允许声明完成。
- 从正式课时和课件索引自动对账来源状态；跳过和排除仍只接受用户明确决定。
- 只把表格、图表、漏斗、思维导图、公式等强知识画面提示送入候选审查，不逐帧保存课程。
- 知识覆盖使用密度自适应窗口；截断时只拆当前失败窗口，不重跑已验证内容。
- 生成每卡一行的 `knowledge_catalog.jsonl`、课程核心知识手册和唯一 `course_state.json`，旧审计在输入变化后自动过期。
- 重复 TXT/EPUB/MOBI/PDF 只有在证据一致时才选一个规范载体，课件页眉页脚/广告/致谢/纯提问页不污染阅读层，非知识视频不硬凑知识点，图表保留必要原图与结构化解读。

## 使用原则

默认在本地处理课程内容。源视频保持只读；正式输出默认只保留文字和 JSON，只有课程根目录 `课件原件/` 可以保存 PDF、Office 文档和图片副本，且绝不保存音视频。不要把课程内容上传到公共 GitHub 仓库，也不要把绝对路径、用户信息、密钥或运行日志提交到仓库。

如果要把本 Skill 安装到支持 Skill 的工具中，请将 Skill 文件夹复制到该工具的 Skill 目录；如果只是存档或分享，直接将本目录上传到 GitHub 即可。上传前仍应运行一次隐私和密钥扫描。

## 公开前检查

- 仓库中没有视频、音频、字幕、逐字稿或真实课程笔记。

- 没有 API key、OAuth token、密码、生产配置或私人仓库地址。

- 已选择适合自己的开源许可证；未添加许可证时，不要对外承诺他人可以复制、修改或再发布。
