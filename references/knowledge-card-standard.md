# 知识点卡片标准 v3.0（公共版）

在生成、修复或验收 `03-知识点卡片.md` 时读取本文件。目标是把来源整理成可查、可学、可直接使用的知识模块，而不是摘要、摘录合集或处理报告。

## 一、生成前建立覆盖清单

按授课顺序盘点：

```text
来源时间段 → 知识点类型 → 具体名称 → 是否有公式或步骤 → 是否有例子 → 是否需要重点核对
```

以下内容分别判断是否成卡：

- 每一种分类或类型；
- 每一套模型、公式、结构或模板；
- 每一个能独立执行的步骤、规则或判断；
- 每一种适用场景、正反例或例外条件；
- 来源中明确展开的问答、练习或作业。

同属一个大主题，不代表可以合并。只有没有新增信息的口头禅和重复表达可以删除。

## 二、固定字段

每张卡至少包含：

```markdown
### 知识点：具体名称

- 所属主题：
- 具体例子：
- 内容性质：老师原话 / 模型整理 / 意译
- 来源时间戳：[HH:MM:SS] 或 [HH:MM:SS–HH:MM:SS]
- 人工核对级别：常规阅读 / 重点核对
```

另按课程类型选择语义字段，不强迫所有课程使用同一套栏目。

## 三、按课程类型选择字段

- 框架方法型：核心定义、解决问题、方法或公式、适用场景、主要特点。
- 课堂推导型：提出的问题、概念解释、推导过程、课堂结论、练习或作业。
- 清单工具型：解决问题、适用场景、写法或操作、方法或公式、主要特点。
- 混合型：保留授课顺序，按每段内容选择字段。

每张卡至少再包含以下两类字段中的各一项：

- 核心定义、提出的问题、概念解释、解决问题；
- 适用场景、方法或公式、写法或操作、推导过程、主要特点、课堂结论、练习或作业。

没有来源的字段写“本课未说明”，不得从常识或外部资料补造。

## 四、例子、原话和核对级别

- 例子必须放在它所解释的知识点内，说明方法如何落地。
- 原课没有可复述例子时，写“本课未发现可独立复述的例子”。
- 能逐字回到来源的短句才标为“老师原话”；模型归纳统一写“模型整理”。
- 时间戳只证明来源位置，不自动证明文字是原话。
- 只有逐字引用、具体数据、易错术语、公式方向、来源歧义或强因果结论标为“重点核对”；普通归纳、步骤和常规方法标为“常规阅读”。

## 五、发布前检查

1. 卡片顺序与授课顺序一致，时间戳不倒退。
2. 覆盖清单中的独立类型、公式、步骤、规则和方法都有对应卡片，或在质量清单说明原因。
3. 标题具体且不重复，禁止使用“卡片 1”“知识点 2”等泛称。
4. 每卡只讲一个主题，不能把多个并列类型塞进一张卡。
5. 必填字段存在且有内容，不能用空字段、残句或“见原文”充数。
6. 具体例子紧跟对应知识点；没有例子时使用明确缺失说明。
7. 内容性质、方括号时间戳和核对级别齐全。
8. 禁止出现“逐字稿摘录（待核对）+ 一句模型总结”的旧式卡片。

任一项失败，课时停在 staging，并在质量清单记录缺口；不得发布到正式阅读区或发起批次验收。
