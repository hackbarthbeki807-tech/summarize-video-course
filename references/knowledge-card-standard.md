# 知识点卡片标准 v3.0

在生成、修复或验收 `03-知识点卡片.md` 时读取本文件。目标是把逐字稿整理成可查、可学、可直接使用的知识模块，而不是摘要、摘录合集或处理报告。

## 一、先建立覆盖清单

生成正文前，先在工作状态中按授课顺序盘点：

```text
来源时间段 → 知识点类型 → 具体名称 → 是否有公式/步骤 → 是否有例子 → 是否需要重点核对
```

把下面内容分别视为独立知识点：

- 每一种分类或类型；
- 每一套模型、公式、结构或模板；
- 每一个能独立执行的步骤、规则或判断；
- 每一种适用场景、正反例或例外条件；
- 老师明确展开的问答、练习或作业。

卡片数量不设固定上限或固定区间；数量由覆盖清单中的真实独立知识点决定，不能为了凑数扩写，也不能为了省事压缩。

同属一个大主题不等于可以合并。比如“数字冲击型、痛点疑问型、热点借势型”应分别成卡，不能压缩为“标题优化”。只删除口头禅、重复表达和没有新增信息的复述。

## 二、按课程类型选择卡片字段

所有卡片都必须包含：

```markdown
### 知识点：具体名称

- 所属主题：
- 具体例子：
- 内容性质：老师原话 / 模型整理 / 意译
- 来源时间戳：[HH:MM:SS] 或 [HH:MM:SS–HH:MM:SS]；若卡片来自课件并列来源，则使用“来源定位：课件：文件名｜第 N 页/第 N 张｜课件原文或 OCR”。
- 人工核对级别：常规阅读 / 重点核对
```

再按课程类型选择语义字段，不强迫所有课程填同一套栏目。

### 框架方法型

优先使用：`核心定义`、`解决问题`、`方法或公式`、`适用场景`、`主要特点`。每个模型或公式单独成卡。

### 课堂推导型

优先使用：`老师提出的问题`、`概念解释`、`推导过程`、`课堂结论`、`练习或作业`。外层顺序必须跟随老师从提问到结论的推进。

### 清单工具型

优先使用：`解决问题`、`适用场景`、`写法或操作`、`方法或公式`、`主要特点`。每种类型、模板或方法单独成卡，具体例子紧跟对应条目。

### 混合型

外层保留授课顺序；每张卡根据本段内容选用上述字段。不要为了统一格式抹掉推导关系，也不要把并列清单合成大段说明。

每张卡除五个固定字段外，还必须至少包含：

- `核心定义 / 老师提出的问题 / 概念解释 / 解决问题` 中的一项；
- `适用场景 / 方法或公式 / 写法或操作 / 推导过程 / 主要特点 / 课堂结论 / 练习或作业` 中的一项。

没有来源的可选字段不必硬填。必须出现的字段没有内容时，明确写“本课未说明”，不得从常识或外部资料补造。

## 三、例子和来源

- 例子不是装饰。老师举出的例子必须放在它所解释的知识点内，让读者直接看到公式或方法如何落地。
- 原课确实没有可复述例子时，写“本课未发现可独立复述的例子”。不要编造例子，也不要用案例页代替该字段。
- 老师原话只能作为证据字段，必须能逐字回到逐字稿；模型归纳统一写“模型整理”。
- 时间戳只证明视频来源位置，不自动证明文字是老师原话。课件原文与 OCR 都不得标为老师原话。
- 视频来源卡的来源时间戳必须保留方括号，使用 `[HH:MM:SS]` 或 `[HH:MM:SS–HH:MM:SS]`；课件来源卡必须改用可验证的页码/幻灯片“来源定位”，不能伪造时间戳。
- 只有逐字引用、具体数据、易错专有名词、需要确认方向的计算公式、逐字稿歧义或强因果/绝对结论才标为“重点核对”；普通模型归纳、编号步骤和常规方法标为“常规阅读”。不得因为出现序号、时间戳或“方法或公式”字段，就把整课全部标成重点；用户不需要逐卡核对全文。

## 四、发布前覆盖检查

逐项检查：

1. 卡片顺序与老师讲课顺序一致，来源时间戳不倒退。
2. 覆盖清单中的每个独立类型、公式、步骤、规则和方法都能对应一张卡，或在质量清单说明为什么不能安全整理。
3. 标题具体且不重复；禁止“卡片 1、知识点 2、核心知识点、方法介绍”等泛称。
4. 每卡只讲一个主题，不能把多个并列类型塞进一张卡。
5. 必填字段存在且有内容；不能用空字段、逐字稿残句或“见原文”充数。
6. 具体例子紧跟知识点；没有例子时使用明确缺失说明。
7. 内容性质、核对级别和来源定位齐全：视频卡带方括号时间戳；课件卡带文件名与页码/幻灯片号。
8. 禁止出现“逐字稿摘录（待核对）＋一句模型总结”的旧式卡片。

任一项失败，课时停在 staging，并在 `05-质量问题清单.md` 记录缺口；不得发布到正式阅读区或发起批次验收。

## 五、人和 AI 都能使用

- 人读：只看卡片就能回答“这是什么、解决什么问题、什么时候用、怎么用、有什么例子”。
- AI 读：标题、字段名、内容性质和来源时间戳稳定，单卡只表达一个主题，便于检索和组合。
- 不追求越长越好。完整保留真实知识密度，同时删除重复口语和没有新增信息的内容。
