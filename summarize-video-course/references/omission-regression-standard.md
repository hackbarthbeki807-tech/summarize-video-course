# 遗漏与质量回归标准 v1.0

## 目的

本标准定义独立的“遗漏与质量回归员”。它不生产内容、不负责最终发布，专门假设前序环节可能漏项，反向检查来源、知识覆盖和交付质量。用户不承担基础找漏工作。

## 固定反向检查链

`来源 → 课时 → 音频/视频 → 课件 → 知识点 → 公式/复用表达 → 案例 → 画面/图表 → 七项文件 → 课程级入口`

## 检查项目

### 1. 来源与课时集合

- 全部音频、视频、PDF、PPT、Word、图片、电子书和未知格式均有来源记录。
- 音频与课件按课时编号、标题和父目录唯一配对；漏配、错配、多配和重复来源必须列出。
- 正式课、导览、前言、预习课、非知识内容、用户明确排除项和失败项分开统计。
- 现场新增或缺失来源会使旧报告过期；批次课时集合必须与授权清单精确一致。

### 2. 知识覆盖

- 对照逐字稿、课件知识提炼稿和知识点覆盖清单，检查定义、分类、步骤、规则、公式、图表和案例是否进入阅读层。
- 逐字稿中只出现但逻辑稿、卡片和案例页都没有的知识，标为遗漏。
- 检查错误合并、重复卡片、重复公式和只剩摘录的空壳知识点。
- 每条缺项必须附时间戳、页码或来源摘录，不能只写“内容遗漏”。

### 3. 复用表达与公式

- 确认完整音频和课件已经扫描，再允许写“本课未发现”。
- 发现 `A+B+C`、步骤链、条件分支、沟通模板、话术或口诀时，必须先输出公式/结构，再输出例子、适用场景、内容性质和来源。
- 不能把模型整理伪装成老师原话，不能把残句当作可复用表达。

### 4. 案例完整性

每个可独立复述的案例至少检查：

`背景/主体 → 原状与触发问题 → 问题分析 → 动作或改造 → 结果 → 关键转折/限制 → 可复用启发 → 来源`

没有来源的指标写“来源未说明”；课堂提示语和逐字稿残句不能替代案例正文。

### 5. 课件、画面与图表

在进入画面检查前，对全部例子执行 [具体例子双关](concrete-example-standard.md)：每例记录位置、来源、真实／老师假设／框架身份、来源核对结果、初学者理解检查的简短依据、未解决项与修复复查结果。检查老师原例是否被压成空泛摘要、是否用AI情境替代、是否把不同主体或因果串在一起；不能只检查案例页而漏掉卡片和公式后的例子。

- 关键表格、流程图、关系图、漏斗和思维导图必须有必要原图或页面、结构化解读、页码/时间戳。
- 原图相对路径必须真实存在且可打开；只有 OCR 文本或只有路径字符串都不算通过。
- 图示关系无法确认时标记“需人工核对”，不能依据失序 OCR 补全含义。
- 页眉、页脚、Logo、广告、联系方式、致谢和纯提问页不能混入知识层。

### 6. 交付与课程级入口

- 七项文件齐全、非空、可打开；`00-本课总览.md` 和 `01-逻辑稿.md` 有“本课学会什么”。
- 卡片数量与覆盖清单一致；每张卡有内容性质和时间戳/页码。
- 课程总览、知识目录、核心知识手册、课件/关键画面索引、推荐逻辑稿和 `course_state.json` 链接真实有效。
- 输出无音视频、无临时文件、无绝对源路径；实时进度入口与真实状态一致。

## 结果与修复闭环

报告写入当前 `work/` 暂存区：

- `omission-regression-report.json`
- `omission-regression-report.md`
- `repair-evidence.md`

每条问题至少包含：课时、缺项、证据位置、风险级别、负责修复环节、修复状态、复查结果。修复必须回到对应生产环节，不能由遗漏员自行补写事实。

固定流程：

`内容生成 → 遗漏回归 → 定向修复 → 遗漏回归复查 → 最终质量审计 → 发布`

存在未解决项时，阻止正式发布、用户验收、下一批启动和 `course_complete` 写入。该检查员不能直接宣布课程完成。
