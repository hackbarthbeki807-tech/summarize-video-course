# 本地运行工程回归标准（公共版）

启动或恢复批次前，验证实际解释器、必要依赖、本地模型、代理环境、来源文件大小与 SHA-256、显式音频—课件映射和最近有效断点。长任务启动器必须保持主进程运行直到 worker 结束，并确认 PID、参数、首个状态更新和阶段产物；不能只凭“进程存在”认定工作在推进。源目录只读，临时媒体只进 `work/`。

运行命令无输出却非零退出时，记录解释器路径、命令参数、退出码、标准输出与错误输出。在同一执行环境逐项测试解释器 `--version`、只读最小表达式、脚本 `--help` 和仅写 `work/` 的安全探针，以区分解释器、依赖、脚本与写入权限问题。可以换用已验证且含项目依赖的本地解释器，但不能以换工具或改路径绕过真实的文件系统限制；正式写入仍须在授权范围内。

批次失败后从有效断点恢复，不重做已验证的转写或课时。运行退出码 0 仍须核对七项文件、课时集合、来源指纹和正式发布状态；发布前先做 `stage-only` 彩排，发布后重开实际文件。
